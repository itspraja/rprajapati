Rohit Prajapati

Researcher, Shell R&D  ·  PhD Candidate, IIT Jodhpur

I work on high-performance computing: designing parallel and distributed systems that make large-scale computation fast, scalable, and efficient. Building on that, I develop dynamic graph algorithms for real-time workloads on distributed and parallel systems.

At Shell R&D, I build production agentic RAG systems over multi-collection vector stores and optimise high-performance computing for large-scale AI workloads.

  • High-performance computing
  • AI workload optimisation
  • Dynamic graph algorithms
  • Model compression
